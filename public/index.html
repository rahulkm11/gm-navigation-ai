Demo Guide

What this demo shows: GM Navigation AI is an agentic, voice-first navigation companion running on the Ultifi platform. Unlike a traditional route-finder, it understands intent, optimizes for EV range, integrates OnStar, and resolves multi-step trip planning — all through natural conversation. This is what next-generation in-vehicle AI looks like.

Scenarios worth trying:

  • ⚡ EV trip to Milwaukee — Watch the AI plan a charging-optimized route, calculate exact battery needs, and select an Electrify America stop along the way
  • 🗓️ Multi-stop trip — Ask to pick up kids, stop for groceries, and head home — the AI optimizes sequence and checks if charging is needed
  • 🚨 Safety event — Simulate a road incident and see the AI engage OnStar, run vehicle diagnostics, and route to a safe stop
  • ☕ POI routing — Add a coffee stop to an existing route and see the AI calculate time/range impact
  • 🌡️ Range in cold weather — Ask how climate affects battery range — the AI uses vehicle telemetry to give a real answer

How the AI works: Every request is processed by a navigation AI model with full vehicle context — battery state, charging preferences, OnStar status, and driver habits. The AI returns structured metadata with each response (action type, route type, confidence, OnStar trigger) which feeds the processing log on the right. This is the observability layer that a GM AI team would use to monitor and improve the system in production.
